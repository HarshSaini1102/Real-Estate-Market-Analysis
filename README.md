# 🏡 Real Estate Market Analysis & Economic Trends

An end-to-end data analytics project exploring urban housing markets, property transactions, macroeconomic indicators, and investment patterns using **Python, MySQL, and Power BI**. 

---

## 🎯 Project Objectives
* **Market Benchmarking:** Analyze property listing distributions, pricing structures, and geographic valuation gaps.
* **Demand & Investor Dynamics:** Evaluate city-level housing demand indexes and rank regions based on investor activity.
* **Affordability Stress Testing:** Measure price-to-income ratios across multiple demographic segments to uncover financial friction points.
* **Supply & Macroeconomic Impact:** Investigate new construction trends and interest rate sensitivities shaping long-term property valuations.
* **Interactive Visualization:** Consolidate multi-source analytical outputs into a multi-page executive Power BI dashboard.

---

## 🛠️ Tech Stack & Tools
* **Data Processing & EDA:** Python (Pandas, NumPy, Jupyter Notebook)
* **Relational Database & Querying:** MySQL (CTEs, Window Functions `LAG`, `ROW_NUMBER`, `DENSE_RANK`, conditional aggregation)
* **Data Visualization & Dashboards:** Power BI (Interactive Slicers, KPI Cards, Drill-throughs)
* **Data Sources:** Structured CSV datasets (`Market.csv`, `Properties.csv`)
